# Проект "DjangoProject"

## Описание:
Проект "DjangoProject" - учебный проект по Python-разработке.
Необходимо создать проект интернет-магазина.

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:Julia87878/DjangoProject.git
```
2. Установите зависимости:
```
pip install django
```

## Использование:
1. Создано приложение под названием catalog.
Настроена маршрутизация для данного приложения.
2. Подготовлены два HTML-шаблона: для домашней страницы home.html и для страницы с контактной информацией contacts.html.
Для стилизации страниц используется Bootstrap.
3. Созданы контроллеры для отображения домашней страницы и для отображения страницы с контактной информацией.
Настроена маршрутизация для этих контроллеров.
